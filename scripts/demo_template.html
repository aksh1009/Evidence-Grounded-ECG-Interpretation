Technical details

Known limitations

Stated openly; the README gives the numbers behind each point.

  • Measurement precision. PR and QT precision is below commercial algorithms (median difference vs 12SL ≈ 10 ms and 16 ms).
  • Wide QRS. QRS duration is overestimated in bundle branch block and paced ECGs.
  • Rare findings. Rare findings (e.g. LVH, RVH, right atrial enlargement) can be under-reported; the CNN has few training examples for some classes.
  • Stock phrasing. The LLM has memorised a stock ischaemia phrase from the translated German reports.
  • Explanations. Integrated Gradients is informative on average, but the explanation for an individual ECG is not always reliable.
  • Labels. PTB-XL long-QT labels are incomplete, which limits evaluation of the QTc rule.
  • Translation. German and Swedish reports were machine-translated, which introduces some noise.
  • Verifier scope. The verifier checks that stated findings exist in the evidence; it does not check “normal” statements (e.g. “normal axis”) against the measurements.
